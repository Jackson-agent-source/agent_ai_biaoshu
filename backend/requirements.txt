# ---------- 数据库驱动 ----------
# PyMySQL 纯 Python 实现，Windows 上不需要编译，比 mysqlclient 更好装
# 仅当 DB_ENGINE=mysql 时才会被使用（见 config/settings.py）
PyMySQL==1.1.2
# ★ 不要删这一行，它不是可选的。
#
# MySQL 8.0 的默认认证插件是 caching_sha2_password。PyMySQL 在**非 TLS 的 TCP
# 连接**上做首次完整认证时，必须用 RSA 公钥加密密码 —— 这段代码在 cryptography
# 缺失时会直接抛：
#     RuntimeError: 'cryptography' package is required for
#                   sha256_password or caching_sha2_password auth methods
#
# 本机开发用的是 sqlite（backend/.env 里 DB_ENGINE=sqlite），所以这条路从来没被
# 跑过，测试也覆盖不到。它只在 Docker 部署（backend 容器连 db 容器）时才会暴露，
# 表现是容器卡在"等数据库就绪"然后无限重启。
cryptography==46.0.3

# ---------- 图片处理 ----------

#   缺了它整个 imaging 链路**在 import 阶段**就炸，配图功能直接不可用。
#
#   用来干三件事：
